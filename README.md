# LOZAN

A Laravel 13 application running on MySQL 8.4, with Vite and Tailwind CSS.

## Stack

| Component | Version |
|-----------|---------|
| PHP | 8.4 (NTS) |
| Laravel | 13.38 |
| MySQL | 8.4.9 (portable, no Windows service) |
| Node.js | 24 LTS |
| Vite / Tailwind | 7 / 4 |

## Local database (MySQL)

MySQL runs as a **portable server** in `C:\tools\mysql-8.4.9` (no admin rights or
Windows service needed). It also starts automatically at Windows logon via a
shortcut in your Startup folder.

```powershell
# start / stop manually
C:\tools\mysql-8.4.9\start-mysql.cmd
C:\tools\mysql-8.4.9\stop-mysql.cmd
```

| Setting | Value |
|---------|-------|
| Host | `127.0.0.1` |
| Port | `3306` |
| Database | `lozan` |
| User | `root` |
| Password | `root` |
| Data directory | `C:\tools\mysql-8.4.9\data` |
| Error log | `C:\tools\mysql-8.4.9\logs\mysql-error.log` |

> Local development credentials only. Never reuse them in production.

## Daily workflow

```powershell
composer run dev      # php artisan serve + queue:listen + vite dev
```

Or run the pieces separately:

```powershell
php artisan serve     # http://localhost:8000
npm run dev           # Vite dev server (HMR)
```

## First-time setup (new machine)

```powershell
composer install
npm install
copy .env.example .env   # then fill in DB_PASSWORD / APP_KEY
php artisan key:generate
php artisan migrate
npm run build
```

## Useful commands

```powershell
php artisan migrate            # run migrations
php artisan migrate:fresh --seed
php artisan test               # PHPUnit / Pest suite
./vendor/bin/pint              # code style
php artisan db:show --counts   # inspect the MySQL connection and tables
```

## Project layout

- `app/` — application code (controllers, models, requests)
- `routes/web.php` — web routes
- `database/migrations/` — schema
- `resources/views/` — Blade templates
- `resources/css/app.css` — Tailwind entry point
- `AGENTS.md`, `CLAUDE.md`, `.ai/` — generated by Laravel Boost (AI guidelines & skills)
